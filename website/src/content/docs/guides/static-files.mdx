Mount a file server under a path. The mount strips the path, so the file server looks up `style.css` for a request to `/static/style.css`:

```go
r.Mount("/static", http.FileServerFS(os.DirFS("public")))
```

`http.FileServerFS` takes any `fs.FS`: a directory on disk, an `embed.FS` compiled into the binary, or a test `fstest.MapFS`.

## Serving files for unmatched paths

To fall back to files for any path no route matches, the way a single-page app often wants, make the file server the 404 handler:

```go
r := gorouter.New(gorouter.WithNotFound(http.FileServerFS(files)))
```

The file server still answers 404 for files that don't exist.
