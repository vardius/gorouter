## Recovering from panics

A panic in a handler would otherwise end in a dropped connection. Wrap the whole router so every route is covered:

```go
func recoverPanics(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		defer func() {
			if err := recover(); err != nil {
				slog.Error("panic", "path", r.URL.Path, "error", err)
				http.Error(w, http.StatusText(http.StatusInternalServerError), http.StatusInternalServerError)
			}
		}()
		next.ServeHTTP(w, r)
	})
}

r := gorouter.New(gorouter.WithMiddleware(recoverPanics))
```
